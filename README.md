# Bible Reader content — PA-Punjabi

This repository contains the Bible Reader SD-card content for **PA-Punjabi**.

## Directory layout

- `text/PA-Punjabi/` — all Bible translations and their original nested folder structure.
- `audio/PA-Punjabi/` — audio Bible book folders and chapter MP3s.
- `gospel/PA-Punjabi/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
